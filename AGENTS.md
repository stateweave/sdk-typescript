# AGENTS.md

StateWeave TypeScript SDK is a low-level SDK primitive, not a framework wrapper.

- The clean-start comparison target is the immutable `GraphFrame -> GraphOps -> StateGraph` pipeline: compile a frame, parse and validate operations, then apply a new state without mutating the prior snapshot. Use these primitives directly, not the public `Agent` wrapper.
- `Agent` remains the only public agent class. Its causal-memory runtime is separate from the GraphFrame pipeline; do not reintroduce parallel agent classes or imply that `Agent` asks the model to author GraphOps.
- Preserve core graph, parser, projection, provenance, imported-state, transactional-state, and tool-safety regression tests, including `Agent` safety coverage.
- Do not expose `messages[]` as a StateWeave primitive. Provider adapters should remain thin HTTP/model primitives.
- The manual web inspector is a pure client of the graph primitives: no model, provider credentials, backend, scoring, or automatic experiments. CLI inspection accepts one task and shows the actual GraphFrame, validated GraphOps, and state transition. Its default is always offline `MockModel`, regardless of provider environment variables. Only `--live` opts into the configured model; the CLI must never load `.env`.
- There is no current comparison baseline or result. New evaluation inputs must come from user-selected existing product material; its source path or example is still required. Await that source and user signoff on inputs, grader, and execution/token budgets before implementation or execution. No model/provider change is approved by this cleanup. Do not invent cases or a baseline, revive a retired harness, automatically run experiments, or make performance/superiority claims. Git history retains removed material.
- Preserve `Agent` invariants: append-only causal state; exact compiled read-set lineage; validated state imports; serialized calls; successful commits only; failed/aborted runs must not overwrite committed state. Keep source provenance and bounded projection intact.
- Keep Quick Start minimal: `Agent`, `createModelFromEnv`, built-in workspace tools, `getState()`/`getGraph()`, and optional state import. Use `streamEvents()` for diagnostics. Default `maxIterations` is 30, without an artificial upper cap; exhaustion should suggest increasing it.
- Default tools (`read_file`, `write_file`, `edit_file`, `bash_command`) remain workspace-scoped and visible in metadata. Preserve traversal/symlink containment. `bash_command` is a read-only, no-profile allowlist: no arbitrary shell, redirects, pipes, command substitution, network commands, or arbitrary interpreters.
- Never read `.env`; it may contain real third-party API keys. Let explicitly authorized commands load configuration without printing it. Never run paid API probes in tests, CI, or default demos.
- Keep code deliberate and organized. Prefer clear types and names, minimal comments, small testable changes, and no duplicate helpers, orphan files, or unnecessary abstractions.
- Verify retained offline tests, typecheck, SDK build, package guard, and the pure-client web build. Packaging must not include obsolete evaluation, integration, or server artifacts, including stale build output.
- Promotion is development -> UAT -> production; do not skip stages unless explicitly approved. SDK branch tags are `development` -> `dev`, `uat` -> `uat`, and `main` -> `latest`. Release, deployment, credentials, and publishing need explicit authority; source cleanup alone does not authorize them.
