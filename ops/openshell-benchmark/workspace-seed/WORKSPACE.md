# Workspace

This is a fresh, isolated OpenShell project directory. Ordinary outbound network access is denied.

The package dependencies in `package.json` are already available through `node_modules`. A local Desmos browser API bundle is available at `vendor/desmos.js`; load it from that relative path instead of fetching it from the network.

Build the requested project in this directory. You may change the package manifest and scripts, but do not remove the locally available dependency versions unless the project no longer needs them.
