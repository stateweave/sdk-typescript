Quick Start

Start a graph-native agent

Primitive: immutable causal graph → bounded context → ordinary action → causal graph. There is one public agent class and no provider transcript primitive.

import { Agent, createModelFromEnv } from "stateweave";

const agent = new Agent({
  model: createModelFromEnv(),
  // tools: myTools,
  // maxIterations: 30,
  // maxPromptTokens: 64_000,
  // projectionTargetTokens: 16_000,
  // systemPrompt: "You are a careful product engineer.",
  // traceDir: ".stateweave/traces"
});

for await (const chunk of agent.stream("Create a tiny HTML todo app in ./todo")) {
  process.stdout.write(chunk);
}

await agent.run("Add keyboard shortcuts.");
console.log(agent.getState());
console.log(agent.getGraph());

The primitive

Each call appends a goal to the same immutable graph. Tool calls, results, resources, retries, and answers record their exact causal parents automatically.

System prompt

Pass provider/system instructions through the model adapter, e.g. new AnthropicModel({ system: "..." }). Graph state stays separate.

Tools

Workspace tools are built in by default: read_file, write_file, edit_file, and bash_command. No tool setup needed to start.

Streaming + internals

agent.stream() yields answer text. Use agent.streamEvents() for compiled contexts, actions, tools, retries, and graph growth.
