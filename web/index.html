Quick Start

Start a graph-native agent

Primitive: StateGraph → GraphFrame → GraphOps → StateGraph. A user turn is a pending graph node; the model returns transactional graph mutations, not a provider transcript.

import { Agent, createModelFromEnv } from "stateweave";

// Optional: seed or resume from a minimal GraphFrame.
// const existingFrame = {
//   frame: {
//     objective: "Continue an existing workspace",
//     currentFocus: "Cortex focus is system_root.",
//     focusNodeId: "system_root",
//     nextExpectedOutput: "Append the next user input and weave it with GraphOps.",
//     activeConstraints: [],
//     availableActions: [],
//     nodeTypes: ["intent", "artifact"]
//   },
//   graph: {
//     nodes: [{ id: "system_root", type: "system", text: "StateWeave system root.", status: "active", confidence: 1, createdAt: new Date().toISOString() }],
//     edges: []
//   }
// };

const agent = new Agent({
  model: createModelFromEnv(), // required

  // tools: myTools, // default: workspace read/write/edit/bash tools
  // maxIterations: 30, // default: model/tool loop limit per user turn
  // systemPrompt: "You are a careful product engineer.",
  // nodeTypes: ["intent", "constraint", "artifact", "decision"],
  // traceDir: ".stateweave/traces",
  // frame: existingFrame // continue from an existing GraphFrame
});

for await (const chunk of agent.stream("Create a tiny HTML todo app in ./todo")) {
  process.stdout.write(chunk);
}

await agent.run("Add keyboard shortcuts.");
console.log(agent.getFrame()?.graph.nodes);

The primitive

Each call appends a user input to the same graph, compiles a focused GraphFrame, receives GraphOps, validates them transactionally, then weaves them back into StateGraph.

System prompt

Pass provider/system instructions through the model adapter, e.g. new AnthropicModel({ system: "..." }). Graph state stays separate.

Tools

Workspace tools are built in by default: read_file, write_file, edit_file, and bash_command. No tool setup needed to start.

Streaming + internals

agent.stream() yields answer text. Use agent.streamEvents() only when you want GraphFrame prompts, GraphOps, retries, and provider metadata.
